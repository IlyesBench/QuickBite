# Definition of Done

A backlog item is Done only when all of these are true:

- [ ] All acceptance criteria checked by someone other than the author
- [ ] Merged to `main` through a pull request with at least 1 approval
- [ ] Tests written for new logic, and `npm test` passes in CI
- [ ] Works in the running app (`npm start`), not only on a branch
- [ ] README updated if setup or behaviour changed
- [ ] Card moved to Done on the board by the Product Owner
